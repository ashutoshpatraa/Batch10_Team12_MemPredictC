# Standard Development Prompt

Read `docs/context.md`, `docs/memory.md`, `docs/plan.md`, `docs/flow.md`, and
`docs/HANDOVER.md` before changing anything. Inspect the existing C source and
Git status. Continue from the exact current state, preserve working behavior,
use standard C11, compile with strict warnings, run relevant tests, and update
all affected documentation before stopping. Never claim system-wide tracking
or invent test results.
